Как уже принято, каждый раз как начинаешь изучать язык программирования всё начинается с строки Hello World.
>> Небольшой комментарий: Я не буду объяснять как установить язык, как запускать нашу программу потому что это совсем не сложно.

И так, давай напишем программу на python которая выведет нам желаемую строку `Hello World`
```python
print("Hello world")
```

```bash
python _lesson0-helloworld.py 
Hello World
```

Функция `print()` позволяет нам вывести (строку, число, булевой параметр и так далее) нужную нам информацию на экран при запуске программы.

Ну получается как-то слишком уж скучно, давай напишем программу которая просит при запуске ввести какие-то данные. Для этого мы используем функцию  `input()`.

```python
print("Hello world!")
input("Введи сюда текст: ")
```

```shell
python _lesson0-helloworld.py
Hello world!
Введи сюда текст: <тут ты вводишь свой текст>
```

Но после ввода текста программа завершается, как сделать так чтобы программа нам вывела введенный нам текст? - Очень просто, нам нужно обернуть функцию `input()` в `print()`
```python
print("Hello world!")
print(input("Введи сюда текст: "))
```

```shell
python _lesson0-helloworld.py
Hello world!
Введи сюда текст: <Привет!>
Привет!
```

Пока просто, да? Мы научились выводить текст на экран и запрашивать текст у пользователя при запуске программы, а также выводить введённое нами значение.

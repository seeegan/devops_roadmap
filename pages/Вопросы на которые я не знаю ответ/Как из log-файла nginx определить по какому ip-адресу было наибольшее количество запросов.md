
Можно воспользоваться утилитой awk которая позволяет разбить строку на разделители

```
awk '{print $номер разделителя}' log_файл
```

Но этого будет мало, мы просто получим список ip-адресов, без числа вхождений

```
awk '{print $1}' | sort -rn | uniq -c | sort -rn log_файл
```

Вот моё решение

```
Вывод:
   2 203.0.113.45
   2 192.168.1.101
   1 198.51.100.22
   1 192.168.1.105
   1 172.16.8.3
   1 10.0.0.55
```


А что делать если утилиты awk нет?

```
cat log.txt | cut -d ' ' -f1 | sort -rn| uniq -c | sort -rn
```

Поменялось написание, в команде cut указывает флаг `-d` в одинарных кавычках указываем разделитель `пробел` и номер поля по разделителю `-f1`

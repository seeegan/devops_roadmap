
Мы уже имеем понимание что такое Ansible, для чего его можно использовать, что такое роли, переменные и так далее (конечно только как обыватели), любую технологию можно изучать до посинения и так и не знать все нюансы. Изучаем только то что пригодиться нам в работе и что мы можем использовать.

У нас есть роль `prepare` давай сделаем так чтобы она хранилась у нас в гите, и при создании новой инфры мы могли просто эту роль из гита подтянуть.

Первым делом нужно инициализировать гит в нашей директории `roles/`.
Делается это не трудно
```
git init /infra/roles
```

У нас появилась новая директория `.git`. Вспоминаем немного линукс, всё что начинается с `.` - это скрытая директория.

Вот у нас есть пустой репозиторий, что делать с ним дальше? Его нужно подключить к удаленному репозиторию в гите. Можно в github, или gitlab. В gitlab удобнее для нас ведь потом мы будем писать свой пайплайн, но это в дальнейшем.

Для начала создадим новый проект в gitlab. Как это делать я не буду показывать, ибо это в UI интерфейсе, там нет ничего сложного.

После создания проекта, в README.MD будет указана инструкция что нужно делать чтобы поместить наши файлы с локального репозитория в удаленный.

Подключаем наш репозиторий к удаленному
```
git remote add origin git@gitlab.com:seegan/ansible-roles.git
```

Создаём ветку `develop`
```
git branch -m develop
```

Добавляем всё что есть в директории
```
git add *
```

Добавляем комментарий
```
git commit -m 'Создал новый проект с ролями и добавил одну роль'
```

Пушим изменения в репозиторий вместе с нашей новой веткой
```
git push -uf origin develop
```

Проверяем что у нас получилось

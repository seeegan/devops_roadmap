Просто разные команды, что придёт в голову то сюда и буду добавлять с описанием команды


**ls** - Просмотр содержимого в каталоге
--
Просмотр содержимого в каталоге
```bash
ls /home/user
```

Присутствуют также разные флаги и аргументы для этой команды, всех их описывать я смысла не вижу


**pwd** - Просмотр текущей директории
--
Команда используется для отображения абсолютного пути в текущей директории
```
pwd
```

cd - Перемещение по директориям
--
Команда используется для перемещениями между директориями
```
cd /home/user
```

head - отобразить первые n строк в файле
--


В целом ничего хитрого, команда просто выводит первые n строк в текстовом файле, можно таким образом почитать конфиг или лог-файл. По дефолту выводит первые 10 строк
```
head -5 file.txt
```

tail - отобразить последние n строк в файле
--
Тут тоже ничего хитрого, выводит последние n строк в текстовом файле. По дефолту последние 10 строк. Но есть интересный флаг `-f` который позволяет в режиме реального времени просматривать лог. 
```
tail -5
```

file - вывод информации о файле
--
Команда позволяет проверить в какой кодировке был конвертирован текстовый файл. Также выводит информацию о типе файла (текстовый или какой-нибудь bash-скрипт)
```
file /usr/bin/man
```

## chmod — изменение прав [[Права доступа в Linux]]

Команда `chmod` (change mode) изменяет права доступа. Она работает в двух форматах.

### Символьный формат

```bash
chmod <кто><действие><права> файл
```

Где:

- **кто**: `u` (владелец), `g` (группа), `o` (остальные), `a` (все)
- **действие**: `+` (добавить), `-` (убрать), `=` (установить точно)
- **права**: `r`, `w`, `x`

whereis
--
Полезная утилита для того чтобы узнать абсолютный путь к программе. Так как в линукс "всё есть файл", то с помощью команды мы можем узнать где этот "файл" команды и находится.
```
whereis ls
```

output
```
ls: /bin/ls
```

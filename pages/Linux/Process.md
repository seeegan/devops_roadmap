# Что такое процесс в Linux?
Программа vs процесс
- Программа - это просто файл на диске, обычный бинарник
	Можем в этом легко убедиться, с помощью команды: `whereis`
	```shell
	whereis ls
	```
	![Pasted image 20261013154525.png](../attachments/Pasted%20image%2020261013154525.png)
		`ls` - это просто файл в каталоге `/usr/bin/` - это и есть программа.

- Процесс - программа, загруженная в память и выполняющаяся. У неё есть свой `PID`, состояние, ресурсы

##### Аналогия
Программа - это рецепт в книге. `Процесс` - это **повар**, который готовит по этому рецепту прямо сейчас

#### Как появляются процессы

Каждый процесс (кроме PID 1) "**рождается**" от "**родителя**". Процесс-родитель вызывает функцию `fork()` - ядро создаёт копию процесса. Потом дочерний может вызвать `exec()` - заменится другой программой.

> Программа сама по себе просто файл который лежит в каталоге
> Процесс - это запущенная программа, для неё выделяются ресурсы, присваивается свой уникальный `PID`, есть владелец, файлы которые могут быть задействованы в ходе выполнения этой программы.

Очень важно понимать различие между обычной утилитой (скажем так инструментом) и процессом (это уже рабочий процесс который задействует этот самый инструмент).
>Лопата - сама по себе просто черенок и железка, но если её берёт человек, тратит время, каллории на выполнение копания какой-нибудь ямы - это и есть процесс, в котором лопата просто инструмент, а человек - владелец процесса.

`PID 1` - process id. Всегда `init` или `systemd`. Родитель всех процессов
`PPID` - parent process id. Номер родителя.

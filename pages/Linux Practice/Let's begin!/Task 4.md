### Часть 2. Диагностика соединений

4. Проверь доступность публичного DNS-сервера (Google DNS):
    
    bash
    
    ping -c 4 8.8.8.8
    
5. Проверь доступность сайта через его доменное имя:
    
    bash
    
    ping -c 4 google.com
    
    **Вопрос:** Какой IP-адрес у [google.com](https://google.com/)?
    
6. Узнай, кто является владельцем домена `google.com` (не вводи в заблуждение, это просто тренировка):
    
    bash
    
    whois google.com | grep -i "registrant"
    

---

### Часть 3. Работа с портами

7. Проверь, открыт ли порт 443 (HTTPS) на сервере для внешних подключений (выполни с сервера):
    
    bash
    
    nc -zv localhost 443
    
    **ИЛИ (если нет nc):**
    
    bash
    
    ss -tulpn | grep 443
    
8. Проверь, открыт ли порт 80 (HTTP):
    
    bash
    
    nc -zv localhost 80
    
9. Проверь, слушает ли твой сервер порт 22 (SSH):
    
    bash
    
    ss -tulpn | grep 22
    

---

### Часть 4. DNS-запросы (важно для DevOps)

10. Узнай IP-адрес сайта `github.com` с помощью `dig` (если нет — установи `dnsutils`):
    
    bash
    
    dig github.com
    
11. Узнай, какие почтовые серверы обслуживают `google.com`:
    
    bash
    
    dig google.com MX
    
12. Выполни обратный DNS-запрос (по IP узнать домен):
    
    bash
    
    dig -x 8.8.8.8
    

---

### Часть 5. Трассировка пути

13. Посмотри, через сколько узлов твой трафик идет до `google.com`:
    
    bash
    
    traceroute google.com
    
    (Если нет `traceroute` — установи: `apt install traceroute`)

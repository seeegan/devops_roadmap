# Управление пользователями

## Полезные команды

### Создание пользователя
- `useradd devops` - минимальное создание
- `adduser devops` - интерактивное создание (рекомендуется)
- `useradd -m -s /bin/bash -G sudo devops` - полный контроль

### Изменение пользователя
- `usermod -aG group user` - добавить в группу
- `usermod -s /bin/bash user` - сменить шелл
- `usermod -d /home/new user` - сменить домашнюю директорию

### Удаление пользователя
- `userdel user` - удалить пользователя
- `userdel -r user` - удалить пользователя и его домашнюю директорию

### Информация о пользователе
- `id user` - UID, GID, группы
- `groups user` - список групп
- `finger user` - полная информация (требуется установка)
